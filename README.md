# TTL — TimeToLinux

> 现在正是切换到 Linux 的好时候。

TTL 是一个 **SKILL 驱动的个性化桌面 Linux 发行版构建系统**。AI 会探查你的电脑环境、询问你的使用习惯，然后通过 GitHub Actions 远程构建一个**专属于你的完整桌面 Linux 发行版**——开箱即用，针对你的设备特化优化，内嵌本地 AI 助手。

## 核心理念

> **开箱即用 × 极致特化**
> 不是"装完能用"，而是"装完就像为你量身定做了三年"。

- **完整桌面体验**：启动即进图形桌面，不是无界面服务器
- **全链路性能优化**：从 GCC 工具链 → glibc → 内核 → 用户空间，全部针对你的 CPU 指令集重新编译
- **开箱即用**：桌面美化、输入法、Windows 软件兼容（Wine/WinApps）全部预配置
- **内嵌 AI**：Qwen3.5-9B 本地问答助手，携带同样的理念持续帮你优化

## 快速开始

### 1. 准备

- 一个 GitHub 账号（本仓库已建好）
- 安装 [Git](https://git-scm.com/)
- 安装一个支持 SKILL 的 AI 助手（如 DeepSeek Harness、Claude 等）

### 2. 加载 SKILL

在你的 AI 助手中加载 `skill/SKILL.md`，然后告诉 AI：

> "我想切换到 Linux，帮我构建一个专属于我的发行版"

AI 会自动：
1. 探查你的电脑环境
2. 问你几个问题（桌面偏好、常用软件、性能倾向等）
3. 每个决策点主动搜索最佳实践 + 避坑
4. 生成构建配置（含决策理由）
5. 指导你推送到 GitHub 触发构建

### 3. 等待构建

GitHub Actions 9 步分批构建（约 4-6 小时）。构建过程中：
- 每步前 AI 主动搜索最新优化手段 + 已知坑
- 进度实时记录，失败可断点续传
- 失败时 AI 提供结构化恢复指导

### 4. 使用

- **体验版**：U 盘启动，直接进入完整桌面试用，不写入硬盘
- **无人值守安装版**：U 盘启动，自动完成安装，全程无需人工干预

## 桌面体验

TTL 构建的是**完整桌面 Linux 发行版**：

| 方面 | 内容 |
|------|------|
| **桌面环境** | XFCE / GNOME / KDE Plasma / i3（根据你选择） |
| **美化** | 图标主题、光标、壁纸、字体全套预配置 |
| **输入法** | fcitx5 + Rime 中文，开箱即用 |
| **Windows 兼容** | Wine 9 + WinApps 预配置 |
| **网络** | 有线/无线/蓝牙自动检测 |
| **声音** | PipeWire 预装，自动检测 |
| **核心应用** | 浏览器、办公、媒体、开发工具预装 |
| **AI 助手** | ttl-ai 桌面应用 + 命令行 + API |

## 性能特化

根据你硬件全链路优化：

| 层级 | 优化内容 |
|------|---------|
| **GCC 工具链** | `-march=<你的CPU>` + LTO + PIE + SSP |
| **Glibc** | `--enable-stack-protector=strong` + CPU 特性自动检测 |
| **内核** | KASLR + StackProtector + GPU 驱动 + NVME + 调度器调优 |
| **用户空间** | 所有软件用优化后的 GCC 重新编译 |

## 内嵌 AI 助手

- **模型**：Qwen3.5-9B（GGUF Q4_K_M，约 5.7GB）
- **运行**：llama.cpp 本地推理，CPU 即可运行
- **访问**：`ttl-ai` 命令行 / 桌面应用 / API（localhost:8080）
- **理念**：携带"开箱即用 × 极致特化"理念，持续针对你的硬件提供优化建议

## 构建进度管理

- **进度文件**：`build-progress.json` 实时记录每步状态
- **断点续传**：构建中断后从断点继续，不重跑已完成步骤
- **失败指导**：失败时自动分类 + 提供恢复方案 + 更新进度

## 稳定性保证

- **版本锁定**：`versions.lock` 锁定所有源码版本，可复现构建
- **决策日志**：每步记录为什么选这个版本/参数，可追溯

- **冒烟测试**：Step 9 启动 VM 验证基本功能
