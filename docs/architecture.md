# TTL 架构文档

## 概述

TTL（TimeToLinux）是一个 SKILL 驱动的个性化 Linux 桌面发行版构建系统。

**核心理念**：开箱即用 × 极致特化

## 三大能力

### 1. 搜索避坑

**双轨搜索**：
- 轨道 1：最佳实践搜索
- 轨道 2：避坑搜索（必须执行）

**输出**：
- `decision-log.json`：决策日志
- `pitfall-report.json`：避坑报告

### 2. 进度管理

**进度文件**：`build-progress.json`

**三级粒度**：
- Step 级别（9 个步骤）
- 包级别（Step 4 的 50 个包）
- 命令级别（configure / make / make install）

**断点续传**：
- 构建中断后从断点继续
- 不重跑已完成步骤

### 3. 失败指导

**失败分类**：
- 类型 A：网络问题
- 类型 B：编译错误
- 类型 C：依赖缺失
- 类型 D：资源不足
- 类型 E：配置错误

**恢复方案**：
- 多个恢复选项 + 风险等级
- 推荐选项
- 断点续传点

## 性能特化

| 层级 | 优化内容 |
|------|---------|
| **GCC 工具链** | `-march=<用户CPU>` + LTO + PIE + SSP |
| **Glibc** | `--enable-stack-protector=strong` + CPU 特性自动检测 |
| **内核** | KASLR + StackProtector + GPU 驱动 + NVME + 调度器调优 |
| **用户空间** | 所有软件用优化后的 GCC 重新编译 |

## 稳定性保证

1. **版本锁定**：所有源码版本锁定（`versions.lock`）
2. **可复现构建**：相同配置 → 相同产物
3. **验证步骤**：每步完成后验证产物
4. **失败恢复**：结构化故障排查指导
